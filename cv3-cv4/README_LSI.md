## Общая подготовка и честное сравнение

В CSV 5572 записи. После удаления 415 точных повторов остаются 5157 сообщений. Одно и то же сообщение не может попасть в обе части.

Один раз выполняем:

```python
train_test_split(indices, test_size=0.2, random_state=42, stratify=labels)
```

Получаем 4125 сообщений для обучения и 1032 для теста, включая 128 спам-сообщений. Разделение совпадает с предыдущей работой. Все 11 моделей используют одни и те же тестовые сообщения.

Категории кодируются как `ham = 0`, `spam = 1`. Положительный класс метрик — spam.

**Только по train изучаются:** словарь TF-IDF, IDF, направления SVD, словарь Word2Vec и векторы слов. Test используется для итогового вычисления метрик. Нейронные сети также обучаются только на train; тестовые категории не участвуют в обучении.

Число эпох и остальные параметры заранее фиксированы. В коде нет выбора лучшей эпохи по тесту или автоматического подбора параметров. Таблица ниже описывает один воспроизводимый эксперимент, а не гарантирует такой же результат на любой выборке.

## 1. Латентное семантическое индексирование — LSI

### Что делает LSI

TF-IDF описывает сообщение тысячами признаков: отдельный столбец для каждого токена. LSI заменяет их меньшим числом **латентных направлений**, которые объединяют совместно встречающиеся признаки.

Например, вместо 7754 координат сообщение получает 100. Компонента может быть связана с группой рекламных слов, но это числовое направление, а не обязательно чёткая тема с человеческим названием.

### SVD

Для матрицы `A` формы «документы × токены» приближённое разложение:

```text
A ≈ U_k × Σ_k × V_kᵀ
```

`k` — выбранное число компонент. Координаты документов в новой системе — `A × V_k`, то есть приближённо `U_k × Σ_k`.

В коде:

```python
svd = TruncatedSVD(n_components=topics, n_iter=7, random_state=42)
train_lsi = svd.fit_transform(x_train)
test_lsi = svd.transform(x_test)
```

`fit_transform()` находит направления **по обучающей TF-IDF-матрице** и переводит обучение в новые координаты. `transform()` переводит тестовые сообщения в **те же направления**. Обучать отдельный SVD на тесте нельзя: координатные системы оказались бы разными.

Применяется прежний TF-IDF `absolute + smoothed`. Экспериментируются `k = 20, 50, 100, 200`. Для каждого размера обучается отдельная логистическая регрессия на полученных векторах.

В `lsi_topics.csv` сохранены слова с самыми положительными и отрицательными коэффициентами первых пяти компонент. У направления SVD два полюса; это не вероятностное распределение слов, а знак компоненты может меняться без изменения смысла разложения. Объяснённая дисперсия характеризует сохранённую вариативность данных, но сама по себе не гарантирует лучшую классификацию.

### Результат

F1 для 20/50/100/200 компонент: `0.9008 / 0.8971 / 0.9157 / 0.9091`.

В этом эксперименте 100 компонент дали лучший F1 среди проверенных размеров. Больше компонент не обязательно лучше: они сохраняют больше деталей, включая шум. Программа выводит все варианты и не выбирает автоматически размер по тесту.

## 2. Word2Vec: статические эмбеддинги

### Что такое эмбеддинг

Каждому известному токену соответствует обучаемый вектор из 64 чисел. Словарь содержит 3479 токенов, встретившихся в train хотя бы дважды. Эти векторы изучаются по соседству слов, **без использования категорий ham/spam**.

Это статические эмбеддинги: токен имеет один вектор независимо от контекста конкретного сообщения. Не используется скачанная модель, обученная на чужом корпусе: векторы обучаются на наших train-сообщениях.

### CBOW и Skip-gram

Для фрагмента `claim free prize now`:

- **CBOW:** по соседним словам предсказывает центральное. Например, по `claim`, `prize`, `now` — слово `free`.
- **Skip-gram:** по центральному слову предсказывает окружающие. Например, по `free` — соседние слова `claim`, `prize`, `now`.

В реализации окно равно двум словам слева и двум справа. Контексты не переходят границы сообщений. Редкие токены исключаются из обучающего словаря Word2Vec.

Стандартная архитектура Word2Vec реализована в PyTorch в классе `Word2Vec`. Для CBOW усредняются векторы контекста; для Skip-gram на вход подаётся один центральный токен. Обе схемы учатся с **negative sampling**:

1. Настоящая пара получает высокий показатель совместимости.
2. Пять случайных отрицательных примеров на каждую обучающую пару получают низкие показатели.
3. Отрицательные токены выбираются с вероятностями, пропорциональными `frequency ** 0.75`.
4. Если случайно выбран настоящий целевой токен, он не считается отрицательным примером.

Это существующие схемы Word2Vec, а не случайные векторы или SVD, названные эмбеддингами. Используются `nn.Embedding`, стандартная negative-sampling функция потерь и Adam. Инициализация случайная, затем веса действительно обучаются: в терминале видна убывающая функция потерь каждой эпохи.

Все нейросетевые части используют PyTorch. Для текущего Python 3.14 не требуется установка старого Gensim или компиляция его расширений.

### Как получить вектор документа

Функция `average_embeddings()` берёт среднее векторов известных токенов:

```text
document_vector = (word_vector_1 + ... + word_vector_n) / n
```

Повторения учитываются: два вхождения одного слова добавляют его вектор дважды. Неизвестные слова пропускаются. Если известных слов нет, возвращается нулевой вектор.

Усреднение теряет порядок: сообщения с одинаковыми словами в другом порядке получают одинаковое представление. По этим 64-мерным векторам обучается логистическая регрессия. Так сравниваются CBOW и Skip-gram.

Полученный F1: CBOW — `0.8916`, Skip-gram — `0.9180`.

## 3. CNN, RNN, LSTM

### Почему здесь нельзя усреднять слова заранее

Усреднённый вектор уже не содержит последовательности слов. Для сетей используем исходные последовательности токенов, а каждый токен заменяем его вектором Skip-gram, обученным на предыдущем шаге.

```text
Текст → токены в исходном порядке → ID токенов → Word2Vec-векторы → сеть → ham/spam
```

Каждая сеть начинает с **одних и тех же исходных Skip-gram-векторов**, но получает собственную копию. Во время классификационного обучения векторы дополнительно корректируются по категориям train — это fine-tuning. Он не изменяет сохранённые исходные Word2Vec-векторы или старт другой сети.

### Длины, неизвестные слова и padding

Функция `encode_sequences()`:

- сохраняет порядок токенов;
- использует ID `0` для заполнителя `<PAD>`;
- использует ID `1` для неизвестного токена `<UNK>`;
- ограничивает последовательность первыми 80 токенами;
- короткие сообщения дополняет нулями справа;
- пустой текст представляет одним `<UNK>`, чтобы длина была хотя бы 1.

Это обрезало 25 обучающих и 7 тестовых сообщений. Параметр `--max-length` позволяет изменить ограничение.

Padding не считается настоящим словом. CNN исключает его позиции из максимума. RNN/LSTM получают упакованные последовательности через `pack_padded_sequence`, поэтому заполнители не меняют конечное состояние.

### CNN

```text
Embedding(64) → Conv1d(64 фильтра, окно 3) → ReLU → max pooling → Dropout → Linear
```

Свёртка ищет локальные комбинации соседних токенов. Максимум по последовательности выбирает наиболее сильный отклик каждого фильтра. Сеть учитывает локальный порядок в окне свёртки, но после pooling точная позиция найденного фрагмента теряется.

### RNN

```text
Embedding(64) → RNN(64 скрытых признака) → последнее скрытое состояние → Dropout → Linear
```

RNN проходит сообщение по порядку. На каждом шаге скрытое состояние зависит от текущего слова и предыдущего состояния. Классификатор получает состояние после последнего настоящего токена.

### LSTM

```text
Embedding(64) → LSTM(64 скрытых признака) → последнее скрытое состояние → Dropout → Linear
```

LSTM — рекуррентная сеть с дополнительной памятью и механизмами, управляющими сохранением и забыванием информации. Это помогает обучать зависимости между удалёнными токенами. В коде из результата LSTM выбирается скрытое состояние, отдельно от состояния памяти.

### Обучение и предсказание

Каждая сеть обучается 8 эпох, размер batch — 64. Используется Adam с `lr=0.001`, dropout `0.2`, `BCEWithLogitsLoss` и ограничение нормы градиента до 5.

Сеть выдаёт одно число — **logit**. Вероятность спама равна `sigmoid(logit)`. При `logit >= 0` эта вероятность не меньше 0.5, и ответ — spam. Во время проверки `model.eval()` отключает dropout, а `torch.no_grad()` отключает расчёт градиентов.

CNN, RNN и LSTM являются настоящими обученными сетями с разными слоями. Они не подменены логистической регрессией. Логистическая регрессия используется только для бинарного baseline, TF-IDF, LSI и усреднённого Word2Vec.
